# Security

`ltspice-mcp` is in early development. The main branch receives security fixes.

If you believe you have found a security issue, email the maintainer listed in `pyproject.toml` (`k.h6570@gmail.com`). Do not open a public issue for an unfixed security bug. Include what you ran, the version, and steps to reproduce.

The threat model for path checks and subprocess limits is in [docs/security.md](docs/security.md).
